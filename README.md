## Issues & Resolutions

### 1. Integrating AI Tools into a Workflow
**Issue:** I was initially unsure how tools like Cursor and Claude would fit together in a single workflow.

**Resolution:** I learned each tool individually before integrating them step-by-step. This approach prevented unnecessary complexity and accelerated getting to a working setup.


### 2. Applying AI Tools to Practical Marketing Tasks
**Issue:** It wasn’t immediately obvious how AI could directly support marketing.

**Resolution:** I connected every new tool back to my core experience with Facebook ads and outreach. This made it clear where AI could help most—in generating ad angles, creating message variations, and speeding up testing cycles.


### 3. Avoiding Over-Reliance on AI
**Issue:** There was a temptation to treat AI outputs as answers rather than inputs.

**Resolution:** I relied on AI to generate ideas, structure, and variations quickly, but made final decisions based on my own campaign experience. This kept execution grounded in proven results.


### 4. Maintaining Simple, Effective Execution
**Issue:** Complex workflows risked slowing down real progress.

**Resolution:** I kept execution focused on one core principle: prioritize speed of testing over system complexity. This ensured the workflow stayed simple and effective.

## Sample 7-Day Growth Plan for a Junior Marketer

**Day 1:** Identify your target audience. Use AI to draft 2–3 different Facebook ad approaches (feature, benefit, or lifestyle-focused).  
**Day 2:** Launch all ads with small, equal budgets.  
**Day 3:** Set up a simple spreadsheet or CRM for incoming leads. Write a basic outreach script; refine it with AI.  
**Day 4:** Start direct outreach (email or DM). Track replies and common questions.  
**Day 5:** Review ad clicks and outreach feedback. Use AI to help improve both ad copy and messages.  
**Day 6:** Adjust or replace underperforming ads; keep refining scripts as you continue outreach.  
**Day 7:** Review which ad worked best and what outreach got replies. Write a quick summary and outline your plan for the next week.
